# Données UNSW-NB15

Placer ici les deux fichiers officiels :

- UNSW_NB15_training-set.csv : 175 341 lignes, 45 colonnes.
- UNSW_NB15_testing-set.csv : 82 332 lignes, 45 colonnes.

Ils sont déjà copiés dans le dossier local préparé. Les CSV sont ignorés par Git et exclus du ZIP de publication. Après un téléchargement depuis GitHub, il faut les récupérer séparément.

Source et conditions d’utilisation académique : https://research.unsw.edu.au/projects/unsw-nb15-dataset

Les données ont leur propre régime d’utilisation ; la licence MIT du code ne s’étend pas automatiquement au dataset. Les empreintes des fichiers utilisés sont enregistrées dans manifest.json.

Il s’agit de trafic réseau de référence ; le dataset ne constitue pas à lui seul une validation sur un déploiement IoT réel.
